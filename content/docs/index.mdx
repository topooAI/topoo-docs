Topoo is the board that defines the core product framing of the system.

The Topoo section explains the product and its shared system configuration before a reader enters a solution board:

- `About` explains what Topoo is and why the product is split into distinct boards
- `Configuration` maps the authority levels where shared system settings belong
- `MCP` defines how external execution clients connect to Topoo capabilities
- `API` defines the automation and control-plane boundary

The boards that follow are the concrete solution lanes and implementation lanes:

- `toAgent` for agent interaction and orchestration
- `toWork` for document and artifact flows
- `toProject` for project architecture and execution structure
- `toMemory` for recall, persistence, and schema-facing memory surfaces
- `TopooUI` for the shared UI foundation and docs primitives used across the product

Topoo desktop docs are organized by work surface. Use the top navigation to jump between product boards, and use **TopooUI** for the shared interface and documentation system rules.

## Current structure

- **Topoo:** desktop-level documentation home.
- **About / Configuration / MCP / API:** product definition and shared system configuration.
- **toAgent / toWork / toProject / toMemory:** board-specific documentation lanes.
- **Topoo Cloud:** the private cloud control-plane model and infrastructure product language.
- **TopooUI:** the shared UI and document system reference library.

## How to read this system

Use `Topoo` first when the question is product-level:

- why the product is split the way it is
- how conversation becomes durable system truth
- how documentation, project, and execution relate
- how the boards relate to one another
- which ideas are core framing versus local implementation

Enter a solution board when the question becomes surface-specific:

- `toAgent` for conversation and operator interaction
- `toWork` for document creation and publishing
- `toProject` for project-centered architecture and execution
- `toMemory` for memory-facing product surfaces

Use `TopooUI` when the question is about shared interface language, docs primitives, and reusable rendering patterns.
